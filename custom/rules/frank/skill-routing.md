# Skill Routing — manual commands + provenance

> Always-on. Lists ONLY what the native skill-description index cannot route:
> the commands below have `disable-model-invocation` and never self-trigger.

- `/sessions` — switch project context by alias.
- `/save-session` — save current session state for later resume.
- `/resume-session` — resume the most recent saved session.
- `/product-cycle` — full BA-gated feature cycle (features, not trivial fixes).
- `/jira` — retrieve or update a Jira ticket.

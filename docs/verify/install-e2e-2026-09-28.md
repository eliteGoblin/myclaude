## Findings

- **INSTALL.md step 6 (fixed in this PR).** The shell loop was refused after `sync --force` ("Contains compound_statement"). The cause is not verified (hypothesis: the newly merged permission rules or hooks). Step 6 is now one `node` command.
- **`custom/settings/permissions.json` line 26 (not fixed).** Every session in the scratch HOME warns: `Bash(git push * :*) mixes * with the trailing :* prefix syntax, so it is matched as a literal prefix ... Use Bash(git push *)`. The rule was meant to catch remote-branch deletes (`git push origin :branch`); today it matches nothing. `Bash(git push *)` would ask on every push, which changes the intent. This rule existed before this PR; Frank decides the replacement.
- **The Claude CLI writes to `settings.json` and `skills/synced/` by itself** at session start (`model` → `opus[1m]`, `.last-complete-round`). INSTALL.md records the never-touch checksums in step 2, after the installing session has started, so its own check compares like with like.
